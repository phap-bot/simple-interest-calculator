# Simple Interest Calculator

A beginner-friendly Bash command-line calculator that computes simple interest from the principal amount, annual interest rate, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Usage

Run the script:

```bash
bash simple-interest.sh
```

Enter:
- Principal amount
- Annual rate of interest (percentage)
- Time period (in years)

The script displays the calculated simple interest and total amount.
